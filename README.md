# 📶 ₹1 Micro-Payment College Wi-Fi System

A full-stack pay-per-use Wi-Fi access management web application built using Node.js, Express, and hosted on Render.

## 🚀 Features
- **Instant UPI QR Code Generation:** Allows users to pay ₹1 for 15 minutes of internet access.
- **UTR Verification:** Prevents double-use of transaction IDs.
- **Dynamic Token System:** Generates unique session tokens upon valid payment.
- **Live Session Timer:** Real-time countdown for active Wi-Fi access sessions.

## 🛠 Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Deployment:** GitHub, Render
